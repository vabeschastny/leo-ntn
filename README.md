# v17 — правки по замечаниям научного руководителя

## Что изменено

Основная конфигурация: порог общего доступа **0 дБ**, **16** повторений преамбулы, пул **48** преамбул (24 ресурса нагрузки при mapping 2:1). Порог нагрузки остаётся 0 дБ. Это разные параметры. Число устройств по умолчанию — 50; сравнительная сетка — **20,40,...,200**. Для объединённого рисунка дополнительно моделируются 50 и 200 устройств: три пары кривых по трём политикам повторов.

По нумерации предыдущего 51-страничного PDF оставлены 24 рисунка. Их полный перечень — figure_catalog.py; сопоставление каждого исходного номера — review_changes.csv. Указанные к удалению графики больше не строятся; их старые изображения не включаются. №4-7 объединены в №3, №37-38 включены в №33, показатель №39 уже представлен №2 и №3 (он не равен дополнению общего отказа на попытку). Суммарная энергия во времени по-прежнему не строится.

## Запуск

Python 3.10+; команды из распакованной папки:

```
pip install -r requirements.txt
python test_model.py
python check_preamble_miss.py
python run.py
python verify_results.py
python build_graphs_pdf.py
```

`run.py` по умолчанию строит все оставленные рисунки и выполняет серии по 20 независимых пролётов на сочетание. Полный запуск может занять несколько минут. Для проверки: `python run.py --passes 2`. Отдельная основная серия: `python run.py --suite core`. Одна популяция: `python run.py --suite core --sensors 80` (50 и 200 всё равно нужны для парного рисунка). `--output` позволяет не перезаписывать прежний набор. Смена параметров должна сопровождаться повторным полным запуском, а не переименованием старых изображений.

В комплект включены готовые результаты. `replot.py` перестраивает оставленные рисунки по имеющимся CSV без новой симуляции. Удалённые рисунки не восстанавливаются. Дополнительные зависимости для PDF: reportlab и Pillow (requirements_pdf.txt).

## Пропуски преамбулы: условие не скрыто

`check_preamble_miss.py` независимо проверяет channel-only preamble miss при первом доступе от 10°, без коллизий, по 100000 реализаций ITU на среду. Для 16 повторений средние вероятности примерно 0.451 / 0.207 / 0.099 по трём средам. Значит, условие 0 < miss < 0.2 НЕ выполняется для города и немного не выполняется для деревни. Отчёт сохраняется в results/preamble_audit. Не применяется поправка мощности/шума или отбрасывание плохих реализаций ради выполнения условия.

Минимум среди проверенных 1/2/4/8/16/32/64 повторений, который выполняет это условие во всех средах, — **64**. В комплекте config_alternative_64.json. Для полного пересчёта альтернативы:

```
python run.py --config config_alternative_64.json --output results_alternative_64
```

Запрошенные 16 остаются основным вариантом, а сравнение 1/16/64 включено в №32. Альтернативный профиль проверен по miss, но его полный набор графиков НЕ выдаётся за выполненный, если он отдельно не запускался.

Порог 0 дБ — условие общего доступа по расчётному SNR без случайного замирания. При текущем бюджете он уже превышен на восходящих 10°, поэтому t₀=0 относительно начала рассматриваемой видимости. Это не означает, что фактический SNR каждого датчика равен 0 дБ. В новой серии по углам порог отдельно выводится из бюджета для каждого заданного угла запуска; эти исследовательские точки не являются базовым запуском с порогом 0 дБ.

## Модель и ограничения

100% успешного доступа не гарантируется: требуется отсутствие коллизий преамбулы и нагрузки, обнаружение преамбулы и декодирование нагрузки. Коллизии all-fail без capture; MsgB отключён. Устройство бесплатно узнаёт исход попытки — условное oracle-допущение, не реализованный канал обратной связи.

После неудачи — фиксированная пауза 5 с или новая независимая равномерная непрерывная пауза U[1;5] с. Затем передача на ближайшей RA occasion сетки 2.56 с, начальное смещение 8 мс. Фактическое ожидание может превышать выбранный backoff. После успеха датчик больше не передаёт.

Круговая орбита над неподвижной сферической Землёй: 600 км, максимум 65°. Одна дальность для всех устройств, новые независимые реализации Loo на каждой попытке; выбранный канал постоянен внутри преамбулы и нагрузки. Ниже 20° статистические параметры удерживаются на 20°, реальная дальность сохраняется. Табличные параметры ITU 2.2 ГГц используются в прежнем приближении для 2 ГГц. Геометрия зданий и пространственная плотность не определяют затенение.

Условный бюджет: EIRP датчика 23 дБм, усиление приёмника спутника 30 дБи, потери 5.3 дБ; шум kTB при 290 K, 15 кГц, NF=6 дБ. Нет дополнительного постоянного сдвига SNR. Это исследовательские параметры, не калибровка реального модема.

Детектор: |sqrt(rho)+CN(0,1)|² >= -ln(P_FA), P_FA=.001. Идеальное объединение даёт 10log10(Nrep) дБ, учтено ровно один раз; выигрыш преамбулы не переносится на нагрузку. Решение только после полной передачи. Формат-0 приближённо 5.6 мс на повторение, при 16 повторениях 89.6 мс; искусственного разрыва нет. Далее 10 мс ожидания и 20 мс нагрузки с одним повторением. Итог после распространения и заданной обработки. Это упрощённая исследовательская, не нормативно валидированная двухшаговая реализация NB-IoT.

Мощности устройства: TX 700 мВт, RX 150 мВт, idle 20 мВт, сон 0.01 мВт. RX в baseline не включается, поэтому изменение только RX-мощности не меняет энергию. Энергия в мДж, внутреннее ядро — в Вт/Дж. Учитываются все отказы, ожидания и сон до конца окна. Энергия на успех = энергия всех устройств всех пролётов / число уникальных успехов. При нуле успехов — N/A. Задержка и энергия до успеха определены только среди успешных; неуспешные показаны отдельно.

## Разные знаменатели и виды рисунков

№1: четыре взаимоисключающие причины отказа (приоритет: коллизия преамбулы, пропуск, коллизия нагрузки, SINR) и их сумма на выполненную попытку за оставшееся окно, в зависимости от угла общего запуска. №33: маргинальные события, которые пересекаются, и их объединение — их нельзя просто складывать.

№2 и №3: успех уникальных устройств, не успех на попытку. №3 объединяет ровно три пары 50/200 устройств. №32: доля уникальных успешных устройств от угла общего запуска, три кривые 1/16/64 повторений на каждой панели. При сравнении повторений угол старта общий, поэтому для его определения используется эталонное число повторений baseline.

№19: отдельная диагностика первого индивидуального достижения порога от -5 до 15 дБ, ожидание от 10°, включая не достигших с ограничением горизонтом; не меняет общий старт основной RA-модели. №20: карта BLER **блока данных** по прежней эмпирической приёмной кривой, а не missed detection NPRACH или общий отказ; 100 устройств при 60°. Карта пересчитывается с текущими параметрами. Шкала остаётся 0..1, здания только фон.

Средние и 95% Student-t интервалы считаются по независимым пролётам. Энергия на успех на графиках — объединённое отношение с bootstrap по пролётам, включая пролёты без успехов. Интервал может быть неограниченным; тогда показана только оценка с пояснением. Малая редкая статистика не превращается в доказательство нулевой вероятности. Накопленные кривые вычислены точным событийным учётом и выведены в общей временной сетке.

## Данные и контроль

passes.csv, summary.csv, timeline.csv и configs_used.json содержат фактически выполненные серии. Журналы первого пролёта — в details. repetition_elevation — сравнение повторений по углам, failure_curves — baseline-подмножество этой серии. Время запуска каждого угла и баланс причин проверяются. Файл review_changes.csv прослеживает все замечания по исходной нумерации; PDF сохраняет эти исходные номера в заголовках.
